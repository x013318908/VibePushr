VibePushr

Single-file PHP app for folder sync. Upload one file: vp.php. Current release: v0.1.3.

Download vp.php (v0.1.3) Release Page GitHub Repository

Quick Setup

  1. Download vp.php.
  2. Upload vp.php to your server (for example under public_html).
  3. Open vp.php in your browser.
  4. Set your admin password on first launch.

Update

  1. Download the latest vp.php.
  2. Replace your existing vp.php file.
  3. Open the page and verify operation.
