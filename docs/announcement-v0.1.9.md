## Long Post

VibePushr v0.1.9 をリリースしました。

VibePushr は、`vp.php` を1ファイル置くだけでフォルダー単位の公開を進められる、軽量な PHP ツールです。

今回の v0.1.9 では、正式リリース後の運用で困りにくいように、公開ドキュメントと確認導線を中心に整えました。

主な内容:

- README と配布ページを整理して、導入 / 更新 / 復旧手順をわかりやすくした
- `CHANGELOG.md`, `SECURITY.md`, リリースチェックリストを追加した
- Playwright のスモーク確認を Windows / Unix 系の両方で回しやすくした
- ブラウザ確認で英語 UI / 日本語 UI の両方を扱えるようにした

配布物はこれまで通り `vp.php` の単一ファイルです。

Release:
https://github.com/x013318908/VibePushr/releases/tag/v0.1.9

## GitHub Release Blurb

VibePushr v0.1.9 improves release readiness around docs, security guidance, and browser-level verification while keeping the production artifact as a single `vp.php` file.
