# 計画

## 予定
- ダークモード（黒背景でハイコントラストな配色）に対応する。
- <input type="file">ではフォルダー選択するたびに、ブラウザーによる確認ダイアログが表示される。ドロップ時にはそれが出なくて快適なので、フォルダー選択時もドロップ時の挙動になるよう揃える。
  - ドロップ時の挙動に揃えるなら、UI上の<input type="file">を隠したい。その代わりに「フォルダーをドロップ、またはここをクリックしてフォルダー選択」という広めの領域を用意したい。ドロップ操作は現状と変わらず画面全体で受けられる方が良い。
- vp.phpが生成するファイルはすべて1つのフォルダーに置きたい。そのフォルダーを非公開にしたい。

## 実装済み
- ブルートフォース対策を実装済み。
- 前回ログインが30日以上前ならログインをロックし、`public_html/.vp_login_guard.json` を削除するまで拒否を継続する。
- ログイン失敗回数上限（`LOGIN_MAX_FAILED_ATTEMPTS=100`）でロックし、`public_html/.vp_login_guard.json` を削除するまで拒否を継続する。
- ログインガード状態ファイル（`.vp_login_guard.json`）の読み書きはロックを使用する。
- フォルダー一覧の文字列をリンク化し、`/対象フォルダー/` を新規タブで開けるようにした。
- 日本語ファイル名問題への対応を実装済み（解決扱い）。
  - 同期時に `relpath` と実保存先の不一致を検出し、`unicode_filename_mismatch` で fail-fast する。
  - jobログに `original_relpath` / `resolved_target` を記録して追跡可能にした。
  - サーバー依存差があるため、UI文言で「一部サーバーでは日本語ファイル名が問題になる可能性」を案内する。
- ログインURLの変更を実装済み。
  - ログイン関連操作はランダム文字列付きURLでのみ受け付ける運用とし、第三者による試行を抑制した。
  - ログインURL情報はログインガード状態とは別管理で保持する。
- MCP関連（認証フロー含む）は VibePushr 本体スコープ外として確定。
  - 本リポジトリではMCP向け仕様追加・実装を行わない。
  - 連携が必要な場合は別プロダクト側で設計・実装する。
  - 記録は `docs/specs/mcp_filemanager.md` を参照。

## 認証運用方針
- 初回起動時にセットアップ画面を表示し、管理パスワードを設定して `.vp_auth.php` へ保存する。
- 認証情報は `.vp_auth.php` のみを参照し、`vp.php` 内に固定ハッシュは持たない。
- ログイン失敗回数上限または長期間未使用でロックされた場合は、`public_html/.vp_login_guard.json` を削除して復旧する。
