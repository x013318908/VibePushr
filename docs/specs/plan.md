# 計画

## 残タスク
- なし

## 実装済み
- ブルートフォース対策を実装済み。
- 前回ログインが30日以上前ならログインをロックし、`public_html/.vp_login_guard.json` を削除するまで拒否を継続する。
- ログイン失敗回数上限（`LOGIN_MAX_FAILED_ATTEMPTS=100`）でロックし、`public_html/.vp_login_guard.json` を削除するまで拒否を継続する。
- ログインガード状態ファイル（`.vp_login_guard.json`）の読み書きはロックを使用する。
- フォルダー一覧の文字列をリンク化し、`/対象フォルダー/` を新規タブで開けるようにした。

## 認証運用方針
- 初回起動時にセットアップ画面を表示し、管理パスワードを設定して `.vp_auth.php` へ保存する。
- 認証情報は `.vp_auth.php` のみを参照し、`vp.php` 内に固定ハッシュは持たない。
- ログイン失敗回数上限または長期間未使用でロックされた場合は、`public_html/.vp_login_guard.json` を削除して復旧する。
